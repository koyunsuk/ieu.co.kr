01 — About

소개

이음유니언(IEU)은 웹과 앱 서비스를 만드는 IT 개발 스튜디오입니다. 기획과 화면 설계, UI 디자인, 개발, 배포와 운영까지 한 흐름으로 진행합니다.

Flutter, Firebase, React 등을 활용해 실제 사용자가 쓰는 서비스를 만듭니다. 기능의학 클리닉 플랫폼, 예술 협회 관리 시스템, 뜨개질 플랫폼 등 다양한 분야의 프로젝트를 수행해 왔습니다.

코드를 작성하는 것만큼이나 고객의 아이디어를 현실로 만드는 과정을 중요하게 생각합니다.
