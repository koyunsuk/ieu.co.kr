OVERVIEW

프로젝트 개요

여러 단계로 나뉜 협회 조직이 일정과 소식을 한곳에서 관리하도록 만든 플랫폼입니다. 운영진이 단톡방에서 주고받은 일정을 AI가 찾아 캘린더에 바로 추가할 수 있게 했습니다.

※ 화면 이미지는 프로젝트 소개를 위해 새로 만든 UI 컨셉으로, 실제 납품 화면과 다를 수 있습니다.

FEATURES

주요 기능

01

3티어 조직 구조

본부·지부·회원 권한을 나눠 각자 필요한 정보만 보도록 구성했습니다.

02

단톡방 AI 일정 추출

카카오톡 단체채팅 내용에서 GPT-4o로 일정을 찾아 캘린더 후보로 제안합니다.

03

크로스플랫폼 앱

React Native 앱과 NestJS 서버로 모바일과 관리 화면을 함께 운영합니다.
