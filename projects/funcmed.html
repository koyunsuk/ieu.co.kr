프로젝트 개요

여러 지점을 운영하는 클리닉이 본사·지점·현장에서 같은 데이터를 보며 일할 수 있도록 구조를 설계했습니다. AI 모델 활용 가이드와 Firestore 데이터 스키마, API 20종을 함께 정의했습니다.

※ 화면 이미지는 프로젝트 소개를 위해 새로 만든 UI 컨셉으로, 실제 납품 화면과 다를 수 있습니다.
